# 大文件登记表（MANIFEST）

> 规则：**单个文件超过 5MB 就不要提交进 git。**
> 传网盘 / 移动硬盘 / Git LFS，然后**在这里登记一行**。
>
> 为什么必须登记：半年后没人记得硬盘上那个 `log-3.zip` 是什么。
> 登记表就是这些文件的"身份证"。

## 为什么要限制体积

- GitHub 对单个文件有硬上限，超过直接推不上去；
- 仓库每大一点，**每个组员的每次 clone 都要多花一份时间**；
- 二进制文件进了 git 历史就删不掉了（`git rm` 只是新增一次删除提交，历史里还在）。

## 登记格式

| 文件名 | 大小 | 产生者 | 日期 | sha256（前 12 位） | 存放位置 |
| --- | --- | --- | --- | --- | --- |
| <!-- 例：2026-10-08-gang-starvation-full.log --> | <!-- 42MB --> | <!-- 张三 --> | <!-- 2026-10-08 --> | <!-- a1b2c3d4e5f6 --> | <!-- 组内网盘 /labs/volcano/ --> |

计算校验值：

```bash
shasum -a 256 <文件>      # macOS
sha256sum <文件>          # Linux
```
